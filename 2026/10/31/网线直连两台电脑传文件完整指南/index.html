网线直连两台电脑传文件完整指南

发表于2026-10-31|更新于2026-10-31|运维（O&M）
|总字数:2k|阅读时长:6分钟|浏览量:

用网线直连两台电脑传文件，核心是将它们组建成一个临时的点对点局域网。现代电脑的网卡大多支持自动翻转，所以普通网线就能用，不必特意准备交叉线。本文以 Windows 为主，并补充连接 Mac 的要点，同时重点解释访问共享时“用户名密码是什么”的问题。

一、硬件连接与网络设置

这是最关键的一步，目的是让两台电脑在“网络”上能找到对方。

1. 连接网线

将网线两端分别插入两台电脑的网口，听到“咔哒”声确保插紧。

2. 配置静态IP地址

因为没有路由器自动分配地址，需要手动设置。原则是IP地址前三段相同，最后一段不同。

  • 电脑 A：IP 地址设为 192.168.1.10，子网掩码 255.255.255.0，网关留空。
  • 电脑 B：IP 地址设为 192.168.1.11，子网掩码 255.255.255.0，网关留空。

Windows 设置路径：
控制面板 > 网络和共享中心 > 更改适配器设置 > 右键“以太网” > 属性 > 双击“Internet 协议版本 4 (TCP/IPv4)” > 选择“使用下面的 IP 地址”进行填写。

Mac 设置路径：
系统偏好设置 > 网络 > 选择“以太网” > 高级 > TCP/IP，将“配置 IPv4”改为“手动”后填写。

3. 验证连通性

在电脑 A 上按 Win + R 输入 cmd，在命令行中输入：

如果看到“来自 192.168.1.11 的回复”，说明连接成功。

二、开启共享并传输文件（Windows ↔ Windows）

网络通了之后，就可以设置共享文件夹来传文件了。

1. 开启网络发现和文件共享（两台电脑都要做）

进入“控制面板 > 网络和共享中心 > 更改高级共享设置”，在“专用”或“来宾或公用”配置文件下，启用网络发现和启用文件和打印机共享。为了方便，可以临时选择“关闭密码保护共享”。

2. 共享文件夹（在源电脑上操作）

右键点击需要传送的文件夹，选择“属性” > “共享”选项卡 > “共享…”，在下拉菜单中选择“Everyone”，点击“添加”，最后根据需要设置“读取”或“读取/写入”权限，点击“共享”完成。

3. 访问并复制文件（在目标电脑上操作）

按 Win + R 键打开“运行”窗口，输入 \\ 加上源电脑的 IP 地址（例如 \\192.168.1.10），回车即可看到共享的文件夹，打开后就能复制粘贴文件了。

三、跨系统传输（Windows ↔ Mac）

如果其中一台是 Mac，方法略有不同。配置好静态 IP 后（例如 Windows 为 192.168.1.1，Mac 为 192.168.1.2），可以选择以下方式：

  • 从 Mac 访问 Windows：在 Windows 上按上述方法共享文件夹。然后在 Mac 的“访达”中，选择“前往” > “连接服务器”（快捷键 Command + K），输入 smb://Windows的IP地址（如 smb://192.168.1.1），输入 Windows 的用户名和密码即可连接。
  • 从 Windows 访问 Mac：在 Mac 的“系统设置” > “通用” > “共享”中，开启“文件共享”，并在“选项”中确保“使用 SMB 共享文件”被勾选。之后在 Windows 的“运行”中输入 \\Mac的IP地址 进行访问。
  • 使用 FTP 工具：如果 SMB 遇到兼容性问题，可以考虑使用 FileZilla 等 FTP 软件。在其中一台电脑上搭建 FTP 服务器，另一台作为客户端连接，这种方式适合大文件批量传输，且跨平台兼容性好。

四、访问共享时“用户名密码是什么”？

你遇到的这个提示，是在访问另一台电脑的共享文件夹时，需要验证你是否有权限。所需输入的用户名和密码，是被访问的那台电脑（也就是提供共享文件夹的电脑，下面称“目标电脑”）上的一个用户账户信息，而不是你自己正在操作的这台电脑的账户密码。

1. 使用目标电脑的登录账户（最常见）

直接输入目标电脑开机登录时使用的用户名和密码即可。

  • 如何查看用户名：如果不确定用户名，可以在目标电脑上按 Win + R 键，输入 cmd 并回车打开命令提示符，输入 whoami 后回车，屏幕上会显示出类似 电脑名\用户名 的格式，后面的部分就是用户名。
  • 关于密码：密码就是该账户的开机登录密码。如果目标电脑使用的是本地账户且没有设置密码，你需要将目标电脑的共享设置改为“无密码保护的共享”，这样访问时就不再需要输入密码了。

2. 使用 Guest 账户（无需密码）

如果目标电脑开启了来宾（Guest）账户并允许访问，当弹出凭据窗口时，可以尝试在用户名一栏输入 guest，密码栏留空直接点击“确定”。

3. 使用专用共享账户

如果不想使用个人的主账户密码，可以在目标电脑上创建一个专门用于文件共享的本地账户（例如命名为 NetworkShare），并为其设置一个密码。之后在访问时，就使用这个新建的账户信息来登录。

4. 如何彻底避免输入用户名密码？

如果希望以后访问都不再弹出这个窗口，可以在**目标电脑（提供共享的电脑）**上调整设置：

打开“控制面板” > “网络和共享中心” > “更改高级共享设置”，在“所有网络”配置下，找到“密码保护的共享”选项，选择“关闭密码保护共享”，然后保存更改。这样一来，同一网络内的设备访问该电脑的共享文件夹时就不再需要凭据了。

5. 连接 Mac 电脑时的凭据

如果目标电脑是 Mac，所需的用户名和密码同样是Mac 上的一个用户账户信息。在 Mac 的“系统设置” > “通用” > “共享” > “文件共享”中，可以查看并设置哪些用户有权访问。输入的密码是该用户的系统登录密码（请注意，不是钥匙串密码）。

6. 特殊情况

  • 用户名格式：如果简单的用户名不行，可以尝试使用 电脑名\用户名 的格式（例如 OfficePC\John）。
  • 凭据冲突：如果确认账户密码无误但仍然报错，可能是系统缓存了旧的错误凭据。可以打开“控制面板” > “用户账户” > “管理你的凭据” > “Windows凭据”，在列表中找到对应电脑的 IP 或名称，将其删除后重试。

五、替代方案与排错提示

如果觉得手动配置 IP 和共享比较繁琐，或者遇到问题，可以试试这些方法：

  • 使用传输软件：可以借助 EaseUS Todo PCTrans、飞秋 等第三方工具，它们通常有图形界面引导，能简化传输过程。
  • APIPA 地址（零配置）：部分现代系统在直连且未设 IP 时，会自动分配 169.254.x.x 网段的地址。一些工具（如 HostDrop）能自动识别并利用这个直连链路，实现“即插即用”式的传输。
  • 常见问题排查：
    • 无法访问共享：首先临时关闭两台电脑的防火墙测试，或确保防火墙允许“文件和打印机共享”通过。
    • 传输速度慢：检查网线是否老化或损坏，并确认两台电脑的网口和网线都支持千兆（Gigabit）标准。

以上就是网线直连两台电脑传文件的完整流程。核心记住两点：先配同网段静态 IP，再访问目标电脑的共享账户。遇到用户名密码提示时，不要输入本机密码，而是输入提供共享那台电脑上的账户信息。
